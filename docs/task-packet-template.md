## Escalation

Report a missing contract, dependency, or prerequisite immediately. Propose the smallest change with an example payload and affected consumers. Continue an independent owned subtask while the coordinator resolves it. Do not edit another owner's files, silently weaken acceptance criteria, or introduce a duplicate interface.

## Required handoff

Return base commit, produced commits, changed paths, contract version, actual validation results, evidence locations, limitations, and whether the task is ready for integration or blocked. Keep the handoff separate from approval; another agent or the coordinator reviews the result.
